Turns a multiplayer server into a survival multiplayer (SMP) world that a group of friends shares over weeks.

Built as a small core plus modules. Server admins switch each one on or off in [b]Settings > Mod Configuration > Terraria Together > Server Settings[/b].

[h2]Modules[/h2]
[list]
[*][b]Gating[/b]: bosses and events stay locked until enough of the group is online (75% and at least 2 players by default), so nobody gets far ahead of everyone else. Summon items aren't used up while locked. Modded bosses are gated automatically when Boss Checklist is installed.
[*][b]Stats[/b]: playtime, deaths, boss kills and PvP kills for each player. [i]/smp stats[/i] shows them, and [i]/smp stats top[/i] shows a top 5 leaderboard.
[*][b]Welcome and rules[/b]: a welcome message every time players join, the server rules on their first join, and an optional "accept the rules before building" step ([i]/smp rules accept[/i]).
[*][b]Discord log[/b]: posts joins, leaves, chat, deaths and first boss kills to a Discord channel through a webhook.
[/list]

[h2]Getting started[/h2]
[list]
[*]Install the mod on the server and on every player's game.
[*]Create a world and join it first: the first player to join a world is added to [b]Admins[/b] automatically.
[*]Type [i]/smp help[/i] in game to see the commands.
[/list]

[h2]Notes[/h2]
[list]
[*]The server makes every decision. Gating and the rules don't apply in single-player.
[*]Other mods can register bosses through [i]Mod.Call[/i].
[*]Source code, full settings reference and changelog: [url=https://github.com/SkimMilkEXE/TerrariaTogether]GitHub[/url]
[/list]

[h2]Discord log setup[/h2]
[list]
[*]In Discord: channel settings > Integrations > Webhooks > New Webhook > Copy Webhook URL.
[*]As an admin in game, type [i]/smp discord url <the url>[/i]. Never paste the URL in normal chat.
[/list]
